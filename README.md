# ComfyUI DeepSeek Prompt Chat

版本：**1.4.1**

在 ComfyUI 中与 DeepSeek 官方 API 连续对话，生成、修改英文绘图提示词。满意后确认，再交给本地图片工作流。适用于需要先讨论画面、再生成图片的工作方式。

## 功能

- 三列界面：左侧对话管理，中间聊天与连接设置，右侧提示词及中英对照。
- 最近 50 个未归档对话，支持新建、搜索、重命名、归档和恢复。
- 每个对话独立保存消息、提示词、草稿、模型设置和提示词版本。
- 浏览器自动保存，并与工作流记录按更新时间合并；切换会话同步恢复提示词。
- TXT 提示词知识库：中英文关键词检索、来源片段展示。
- 中英对照以标签横向排列，自动换行；出图只使用纯英文提示词。
- 版本历史默认折叠，支持恢复旧版本。复制和手动保存版本按钮已隐藏，生成结果和编辑仍自动记录。
- 聊天不会触发图片生成；修改或切换提示词后必须重新确认。

## 安装

将仓库文件夹放到 `ComfyUI/custom_nodes/` 下，确认 `__init__.py` 位于该文件夹根目录。使用 ComfyUI 自己的 Python 环境安装依赖：

```sh
python -m pip install -r requirements.txt
```

重启 ComfyUI 后端，再重新加载浏览器页面。在节点搜索中输入 `DeepSeekPromptChat` 或「DeepSeek 连续对话」。

**从旧版升级：** 备份原目录与 `.env`，将旧版 `web/chat*.js` 移出 `web` 目录，只保留本版 `chat-v1.4.1.js` 入口，避免重复加载。保留原来的 `.env`，重启后端并刷新页面。

## 使用

1. 将节点「已确认提示词」输出接到 CLIP 文本编码的 `text` 输入；必要时右键将 text 控件转换为输入。
2. 点击「打开 DeepSeek 连续对话」，输入 DeepSeek 官方 API Key，选择模型。
3. 发送画面需求并持续修改。右侧英文提示词可以手动编辑；下方标签显示对应中文。
4. 「仅确认提示词」写入节点；「确认并生成图片」写入并提交当前整个工作流。

复杂工作流中的其他输出分支也可能随提交执行。示例工作流位于 `example_workflows/`，使用 `rinFlanimeIllustrious_v30.safetensors`，需要自行安装模型，也可替换为已有模型。内置提示词规则偏向 SDXL / Illustrious 动漫模型。

## 对话与版本

所有会话在当前浏览器、同一访问地址下共享，并可随工作流保存。建议用 Ctrl+S 保存工作流作为备份。清除网站数据或更换浏览器后，需要从已保存工作流恢复。

达到 50 个未归档对话时，会提示先归档，不自动删除旧记录。选中「显示已归档」可查看或恢复。提示词版本属于各自的对话；恢复旧版本不会删除较新版本。

翻译属于生成时的英文结果。手动编辑英文后会提示对照尚未更新，可继续发送给 DeepSeek 更新。旧版结果不会自动联网翻译。

## TXT 知识库

展开「TXT 提示词知识库」后导入文件。支持 UTF-8、GBK / GB18030 和 UTF-16 LE；每个文件最多 1 MB，最多 20 个文件、合计 80 万字符。同名文件会替换浏览器中的副本。

建议每段包含中文主题、适用场景和英文提示词，段落间空一行。格式参考 `examples/提示词知识库示例.txt`。每轮最多检索 4 个片段，每个最多 800 字符。这是关键词匹配，不是向量语义检索。

知识库文件保存在浏览器中，不随工作流保存；每轮选中的片段会发送给 DeepSeek。原始 TXT 请自行备份。

## API Key 与数据

- 输入框中的 Key 只在页面内存保留，刷新后需重新输入，不写入工作流。
- 可复制 `.env.example` 为本节点目录下的 `.env`，填写 `DEEPSEEK_API_KEY`。
- Key 优先级：窗口输入 → 进程环境变量 → 本节点 `.env` → 相邻 `llm-toolkit/.env`。
- 请求发送到 `https://api.deepseek.com/chat/completions`，携带当前会话历史及命中的知识库片段，由 DeepSeek 账户计费。
- 会话由本插件管理，不同步到 DeepSeek 官网聊天列表。
- 工作流及生成图片的工作流元数据可能包含会话记录。分享前请检查。
- 仓库不包含真实 Key、个人对话、私人知识库、图片或模型文件。

## 限制与排错

模型选项为 `deepseek-v4-flash` 和 `deepseek-v4-pro`，可用性和别名路由由 DeepSeek 官方服务决定。每次请求最多 160 条历史消息，过长时请新建会话。

401 表示 Key 无效，402 表示余额不足，429 表示请求过于频繁。格式错误、超时或中英标签不对应时，请重试；失败不会覆盖原有会话结果。英文框内存在中文时禁止出图。

找不到按钮或界面仍旧时，请保存工作流，重新加载页面，检查是否残留多个 `chat*.js` 入口。浏览器存储写入失败时底部会显示提示，请及时保存工作流。
